# SublimeTextPatch
El siguiente script de powershell parchea Sublime Text de forma sencilla y rapida sin sufrir buscando cracks

Primero ejecuta este comando de powershell para que el script se ejecute sin restriccion:

Set-ExecutionPolicy Unrestricted -Scope CurrentUser

Descarga el archivo .ps1 en la ubicacion que desees ...

Y ejecutalo en una terminal de windows (Windows 11) o powershell (Windows 10) - No necesita permisos de administrador, sin embargo es sugerido

Disfrutalo!!
